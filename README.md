# أحاسيس الجمال الطبي

موقع مجمع أحاسيس الجمال الطبي في عرعر.

## التشغيل المحلي

```bash
npm ci
npm run dev
```

## النشر

يُجهّز الموقع للنشر في مجلد `docs`. في إعدادات المستودع على GitHub، اختاري **Deploy from a branch**، ثم فرع `main` ومجلد `/docs`.

لإنشاء نسخة محدثة للنشر:

```bash
npm run build
```

ثم انسخي محتويات `dist` إلى `docs` وارفعي التغييرات إلى فرع `main`.
